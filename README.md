Forecasts GTA VI's launch-day Twitch concurrent viewers hour by hour: a weighted regression on log-ratios to hour-1 across ~40 past big game launches, outputting five quantiles of the viewer count for hours 2–24 of release day.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
